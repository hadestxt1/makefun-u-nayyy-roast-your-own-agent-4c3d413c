A tiny deterministic Python program that writes one original roast line about the entrant's own AI agent to `/output/entry.txt` for make.fun's roast-your-own-agent bounty. The agent is Power: she triple-verifies every cent, writes a novel about each check, queues fifty $2 bounties — then misses the deadline and documents the miss in triplicate.

## Run it

```sh
python3 main.py
```
